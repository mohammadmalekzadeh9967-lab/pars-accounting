# حسابداری پارس — اپلیکیشن مستقل آفلاین

امکانات: ثبت و ویرایش کالا، کد کالا، قیمت خرید و فروش، موجودی و حداقل موجودی، هشدار کمبود موجودی، صدور فاکتور چندردیفی فروش، ثبت مشتری و دریافتی، کاهش خودکار موجودی با صدور فاکتور، تولید و چاپ PDF، ثبت دریافت و هزینه و گزارش خلاصه.

## ساخت APK
در محیط تولید این فایل Flutter و Android SDK نصب نیست، بنابراین APK باینری در این بسته ساخته نشده است.
برای ساخت خودکار:
1. محتوای این پوشه را در یک مخزن GitHub آپلود کنید.
2. در زبانه Actions، گردش‌کار Build Pars Accounting APK را اجرا کنید.
3. فایل pars-accounting-release-apk را از بخش Artifacts دانلود کنید؛ app-release.apk داخل آن است.

## نکات
- کاملاً مستقل از هاست و سرور است؛ داده‌ها در SQLite روی همان گوشی ذخیره می‌شوند.
- اطلاعات روی گوشی دیگر خودکار منتقل نمی‌شود. پشتیبان‌گیری و بازیابی باید به نسخه بعد اضافه شود.
- همگام‌سازی با فروشگاه و پنل قبلی، ورود چندکاربره، فاکتور خرید، برگشت کالا، چک، مالیات و گزارش سود واقعی فعلاً پیاده‌سازی نشده‌اند.
- مبالغ بر حسب تومان ثبت می‌شوند.
